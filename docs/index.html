不激活后台窗口的 Windows 操作工具

Non Activating Operate 是一款轻量的 Windows 托盘工具。

启动程序后按 Ctrl+F 开启功能，即可点击后台窗口中的按钮、链接和媒体控件，而不会把目标窗口切到前台，也不会抢走当前输入窗口的键盘焦点。点击后台输入框时，程序会临时将窗口切换到前台并定位光标，支持正常键盘和中文输入法输入。

支持鼠标左键、右键、中键、双击、滚轮、拖拽和文件拖放，并提供保持当前窗口遮挡关系、自定义快捷键和开机启动等功能。
